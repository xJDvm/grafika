## ¿Qué es Adobe Illustrator?

Adobe Illustrator es una herramienta de diseño gráfico para crear ilustraciones y gráficos vectoriales. Los vectores describen puntos, líneas y curvas mediante fórmulas matemáticas. Por eso se pueden ampliar o reducir sin perder nitidez. Son una buena opción para logotipos, iconos, ilustraciones, gráficos web y tipografías.

## Vector frente a mapa de bits

### Gráficos vectoriales

- Se construyen con puntos, líneas y curvas, no con una cuadrícula de píxeles.
- Mantienen la calidad al cambiar de tamaño.
- Son apropiados para logotipos, ilustraciones, iconos y diseños que deben reproducirse en distintos formatos.
- Algunos formatos vectoriales comunes son SVG, AI y EPS.

### Imágenes de mapa de bits

- Están formadas por píxeles; cada píxel contiene un color.
- Al ampliarlas mucho, los píxeles se hacen visibles y la imagen puede verse borrosa o pixelada.
- Funcionan bien para fotografías, imágenes escaneadas y escenas con mucho detalle o degradados.
- Algunos formatos comunes son JPG, PNG y GIF.

## Conoce la interfaz

Al comenzar, ubica estas áreas principales:

- **Barra de menú:** opciones como Archivo, Edición, Objeto y Texto.
- **Panel de herramientas:** selección, pluma, formas y otras herramientas de dibujo y edición.
- **Paneles:** controles de color, capas, propiedades y otros ajustes.
- **Mesa de trabajo:** área donde se crean y organizan los diseños. Un documento puede tener varias mesas.

También puedes personalizar el espacio de trabajo y configurar un documento nuevo según el proyecto.

## Herramientas de dibujo

La herramienta **Pluma** permite crear trazados y curvas Bézier con precisión. Las herramientas de **formas** sirven para dibujar rectángulos, elipses, polígonos y estrellas. El **Lápiz** permite realizar bocetos y trazos a mano alzada.

Al editar un trazado puedes añadir o quitar puntos de ancla, moverlos y ajustar sus segmentos para cambiar la forma.

## Selección y transformación

- **Selección:** mueve y transforma objetos completos.
- **Selección directa:** trabaja con puntos de ancla y segmentos individuales.
- **Transformación:** rota, escala, refleja o distorsiona objetos.
- **Varita mágica:** ayuda a seleccionar objetos con atributos visuales similares.

## Color

Illustrator permite elegir modos de color según el destino: **RGB** se utiliza principalmente para pantallas y **CMYK** para impresión. El panel Color sirve para elegir valores y crear degradados; el panel Muestras permite guardar y reutilizar colores. El Cuentagotas toma un color de un objeto existente.

Puedes aplicar color al relleno o al trazo y crear degradados lineales, radiales o de forma libre.

## Capas

Las capas separan y organizan los elementos del diseño. Desde el panel Capas puedes crearlas, eliminarlas, ocultarlas o bloquearlas. El orden de las capas determina qué objetos quedan delante y cuáles detrás.

## Atajos útiles

| Acción | Atajo indicado en el material |
| --- | --- |
| Guardar | `Ctrl + S` |
| Copiar / pegar | `Ctrl + C` / `Ctrl + V` |
| Pegar en el mismo lugar | `Ctrl + F` |
| Deshacer / rehacer | `Ctrl + Z` / `Ctrl + Shift + Z` |
| Desplazarse por el lienzo | Barra espaciadora + clic izquierdo |
| Zoom | `Alt` + rueda del ratón |
| Duplicar | `Alt` + clic izquierdo |

Los atajos pueden variar según el sistema operativo y la configuración de Illustrator.

## Practica con formas básicas

1. Crea rectángulos, elipses, triángulos y polígonos.
2. Selecciona y transforma las figuras.
3. Prueba distintos rellenos y trazos.
4. Combina las formas para construir una composición sencilla.

Este ejercicio reúne dibujo, selección, color y organización por capas.
