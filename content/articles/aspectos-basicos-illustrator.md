## Pincel

El Pincel crea trazos libres y orgánicos. Puedes ajustar el grosor, la forma y la opacidad; con una tableta gráfica, algunos pinceles también responden a la presión y a la velocidad. Los trazados creados siguen siendo editables con Selección directa.

### Cómo usarlo

1. Elige el Pincel en la barra de herramientas.
2. Abre **Ventana → Pinceles** y selecciona un pincel.
3. Ajusta grosor, opacidad y modo de fusión desde la barra de control o las opciones del pincel.
4. Haz clic y arrastra sobre la mesa de trabajo.
5. Si necesitas corregir el trazado, mueve sus puntos de ancla con Selección directa.

### Cargar pinceles y crear texturas

Los paquetes de pinceles suelen venir en archivos comprimidos. Descomprímelos, abre el panel Pinceles, selecciona **Biblioteca de pinceles → Otra biblioteca…** y elige el archivo de Illustrator. La biblioteca se abre aparte y no sustituye los pinceles existentes.

Para mantener una textura dentro de una forma, usa un objeto cerrado, selecciona un pincel de textura y activa el modo **Pintar dentro**. La pintura quedará limitada a la forma. Puedes modificar su intensidad con la opacidad en el panel Transparencia.

Trabaja las texturas en capas separadas y prueba diferentes pinceles y opacidades para conservar la posibilidad de editarlas.

## Lápiz

El Lápiz permite dibujar a mano alzada con control sobre el trazado. En sus opciones puedes ajustar la fidelidad y la suavidad. Después de dibujar, edita los puntos con Selección directa o utiliza la herramienta Suavizar para reducir irregularidades.

Una tableta gráfica puede ofrecer control adicional sobre la presión y el grosor. Prueba distintas opciones del Lápiz hasta encontrar un trazo adecuado para el tipo de boceto.

## Panel Apariencia

El panel Apariencia muestra los atributos visuales de un objeto: rellenos, trazos, efectos y opacidad. Permite apilar varios atributos y editarlos sin modificar la forma original.

Abre **Ventana → Apariencia** y selecciona un objeto. Desde el panel puedes añadir un relleno, un trazo o un efecto; al seleccionar un atributo puedes ajustar su color, grosor, opacidad y opciones. Arrastra los atributos para cambiar su orden: los que están arriba se ven por delante.

## Degradados

Un degradado transiciona entre dos o más colores. Illustrator ofrece:

- **Lineal:** la transición sigue una línea.
- **Radial:** el color se expande desde un punto central.
- **Forma libre:** permite distribuir transiciones más orgánicas.

Selecciona un objeto y abre **Ventana → Degradado** para aplicar un tipo, cambiar los colores y ajustar la posición o el ángulo. La herramienta Degradado (`G`) permite editar la dirección y la longitud directamente sobre el objeto. Las transiciones sutiles pueden dar profundidad; también puedes usar degradados para simular luz y sombra.

### Malla de degradado

La malla crea una cuadrícula de puntos de ancla sobre un objeto. Cada punto puede tener un color distinto, lo que permite construir transiciones complejas. Selecciona la herramienta Malla (`U`) y añade puntos, o usa **Objeto → Crear malla de degradado**. Con Selección directa (`A`) puedes elegir los puntos y ajustar sus colores y posiciones.

## Pluma

La Pluma construye trazados precisos con puntos de ancla. Un clic crea un segmento recto; al arrastrar un punto aparecen manejadores que controlan la curva Bézier. Haz clic en el primer punto para cerrar una forma. Para terminar un trazado abierto, usa `Ctrl` y haz clic fuera del trazado.

1. Selecciona la Pluma (`P`).
2. Haz clic para colocar el primer punto.
3. Añade puntos para formar segmentos rectos; haz clic y arrastra para definir curvas.
4. Ajusta los manejadores y los puntos con Selección directa (`A`).
5. Cierra la forma al volver al punto inicial.

`Shift` ayuda a restringir la dirección de los segmentos. También puedes ajustar los manejadores al terminar el arrastre o probar la herramienta Curvatura.

## Trazos y anchura

El trazo es el contorno visible de un objeto. Puedes cambiar su grosor, color, estilo (continuo, discontinuo o punteado), perfil, extremos y vértices desde **Ventana → Trazo**. Selecciona primero el objeto y modifica los valores desde el panel.

La herramienta Anchura (`Shift + W`) modifica el grosor en puntos concretos de un trazado. Coloca el cursor sobre el trazado y arrastra hacia fuera para ensanchar o hacia dentro para estrechar. Añade más puntos de anchura para controlar distintos tramos; guarda los perfiles que quieras reutilizar.

## Buscatrazos

Buscatrazos combina y divide formas para crear figuras complejas. Sus modos de forma incluyen unir, restar, intersecar y excluir; las operaciones de trazado permiten dividir, cortar, combinar, recortar, contornear o restar el fondo.

Para usarlo, crea dos o más formas, selecciónalas y elige el modo de forma o la operación de Buscatrazos que necesites.

## Máscara de recorte

Una máscara de recorte usa una forma superior para ocultar las partes de los objetos que quedan fuera de ella. Es una operación reversible: puedes editar el contenido o liberar la máscara después.

1. Coloca la forma que será la máscara por encima del contenido.
2. Selecciona la máscara y los objetos que quieres recortar.
3. Elige **Objeto → Máscara de recorte → Crear** o usa `Ctrl + 7` (Windows) / `Cmd + 7` (Mac).
4. Para editar el contenido, haz doble clic sobre el objeto enmascarado.
5. Para recuperarlo, elige **Objeto → Máscara de recorte → Liberar** o usa `Ctrl + Alt + 7` / `Cmd + Option + 7`.

## Herramienta Texto

Illustrator permite crear texto de punto para títulos cortos, texto de área para párrafos y texto sobre trazado para seguir una curva o línea. También ofrece texto vertical.

Selecciona la herramienta Texto (`T`). Haz clic para escribir texto de punto o arrastra para definir un área. Usa los paneles Carácter y Párrafo para cambiar fuente, tamaño, estilo, espaciado, alineación y sangrías. El texto se puede editar después mientras siga siendo texto.

### Convertir texto en contornos

Al crear contornos, cada letra pasa a ser un trazado editable y deja de comportarse como texto. Selecciona el texto y elige **Texto → Crear contornos** o **Expandir**. Atajos: `Ctrl + Shift + O` (Windows) y `Cmd + Shift + O` (Mac). Después puedes modificar los puntos y combinar las formas con Buscatrazos.

## Texturas, imágenes y modos de fusión

Para aplicar una textura, importa la imagen desde **Archivo → Colocar**, crea la forma que la contendrá y coloca la imagen sobre ella. Puedes usar una máscara de recorte o crear una muestra de motivo. Desde **Ventana → Transparencia** ajusta la opacidad y prueba modos como Multiplicar, Trama, Superponer, Oscurecer, Aclarar, Color o Luminosidad.

## Guías y cuadrículas

Las guías son líneas no imprimibles que ayudan a alinear elementos. Muestra las reglas desde **Ver → Reglas → Mostrar reglas** (`Ctrl + R` / `Cmd + R`) y arrastra desde una regla para crear una guía. También puedes convertir un objeto en guía desde el menú contextual. Bloquéalas cuando no quieras moverlas accidentalmente.

La cuadrícula ofrece una referencia de líneas horizontales y verticales para alinear objetos. Actívala desde **Ver → Mostrar cuadrícula** y, si quieres, activa **Ver → Ajustar a cuadrícula**. Sus opciones están en **Edición → Preferencias → Guías y cuadrícula** (`Ctrl + K` / `Cmd + K`). Las guías y la cuadrícula no se imprimen.
